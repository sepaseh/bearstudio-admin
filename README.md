# Bear Studio Admin

This repository is the source for the independent Bear Studio administration panel.
The source-preparation phase admits finite, cumulative modules and verifies their
behavior in isolation. This phase does not include an application entry point.

Use the Node release in [.nvmrc](.nvmrc) and follow the [validation guide](docs/validation.md)
for local checks. See [contribution procedures](CONTRIBUTING.md) before preparing
a change.
